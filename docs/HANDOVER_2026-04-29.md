## 🎯 Hệ thống này làm gì?

Đây là **phần mềm nội bộ** giúp nhân viên visa xử lý hồ sơ khách hàng nhanh hơn. Phần mềm tự động hóa gần như toàn bộ quy trình:

1. **Nhận hồ sơ từ Google Drive** → AI tự quét, kiểm tra đủ thiếu giấy tờ
2. **Dịch tài liệu** (Khai sinh, Tư pháp, CMND...) → AI đọc + dịch + giữ nguyên layout
3. **Đóng mộc & Giáp lai** → Tự động đóng dấu công ty lên bản dịch PDF
4. **Đẩy bản dịch lên Drive** → Tự động upload + xóa bản gốc
5. **Booking vé máy bay & khách sạn** → Tích hợp SerpAPI tìm chuyến bay thực tế
6. **Sinh lịch trình du lịch** → AI viết lịch trình khớp vé + phòng
7. **Sinh bảo hiểm du lịch** → Sinh chứng nhận Liberty/Chubb tự động
8. **Viết thư giải trình** → AI đọc hồ sơ → viết cover letter chuẩn đại sứ quán

## ⚡ Cài đặt & Chạy

### Bước 1: Cài Python 3.10+
Tải tại: https://www.python.org/downloads/
> ⚠️ Nhớ tích ✅ "Add Python to PATH" khi cài!

### Bước 2: Chạy lần đầu
Bấm đúp vào file **`start.bat`** — Script sẽ tự động:
- Tạo môi trường ảo (`myenv/`)
- Cài thư viện (`requirements.txt`)
- Tạo file `.env` nếu chưa có
- Mở trình duyệt tại `http://127.0.0.1:8000`

### Bước 3: Điền API Keys vào `.env`
```
OPENAI_API_KEY=sk-...           ← BẮT BUỘC (lấy từ platform.openai.com)
SERPAPI_KEY=...                 ← Cần cho tìm chuyến bay
OPENAI_MODEL=gpt-5-mini
OPENAI_VISION_MODEL=gpt-4o-mini
```

### Bước 4: Cấp quyền Google Drive (chỉ lần đầu)
1. Lấy file `client_secret.json` từ Google Cloud Console
2. Bỏ vào thư mục gốc (cùng chỗ với `server.py`)
3. Chạy `start.bat` → Hệ thống tự mở trình duyệt xin quyền Drive → Sinh ra `token.json`

> ⚠️ **KHÔNG push** `client_secret.json` và `token.json` lên git!

## 🗺️ Sơ Đồ Luồng Chính

### Luồng A: Hồ Sơ Visa (Từ Drive)
```
Sale upload hồ sơ lên Drive
    ↓ (Đổi tên folder thêm "-DONE" hoặc "-Dịch")
Bot tự phát hiện (quét mỗi 30s)
    ↓
AI kiểm tra đủ/thiếu giấy tờ
    ├─ THIẾU → Drive: "🚨 ... - THIẾU (tên file)"
    └─ ĐỦ → Drive: "✅ ... - Đang dịch"
              ↓ Tải file về máy (translation_workspace/)
              ↓ Nhân viên dịch từng file trên web
              ↓ Đóng mộc + Push lên Drive + Xóa bản gốc
              ↓ Bấm "Báo cáo Dịch Xong"
              ↓ Drive: "✅ ... - Đang khai"
              ↓ Local: move workspace → Khai Imm/
```

### Luồng B: Dịch Thuật Thuần (Không qua validation)
```
Folder tên kết thúc bằng "-Dịch"
    ↓ Bot phát hiện → bỏ qua kiểm tra
    ↓ Drive: "✅ ... - Đang dịch"
    ↓ Tải về → Dịch → Đóng mộc → Push
    ↓ Bấm "Báo cáo Dịch Xong"
    ↓ Drive: "✅ ... - DONE"  ← (Khác Luồng A!)
    ↓ Local: move → Khai Imm/
```

> **Cách hệ thống phân biệt:** File `_files_meta.json` trong mỗi workspace có trường `flow_type`:
> - `"visa"` → Luồng A → khi xong → "Đang khai"
> - `"translation"` → Luồng B → khi xong → "DONE"

## ⚠️ Những Điều CẦN BIẾT

### 1. File nhạy cảm — KHÔNG đẩy lên git
```
.env                    ← API keys
client_secret.json      ← Google OAuth credentials
token.json              ← Google Drive access token
translation_workspace/  ← Hồ sơ khách đang xử lý
Khai Imm/               ← Hồ sơ đã xong (lưu trữ)
```

### 2. Trạng thái folder trên Google Drive
| Tên folder | Ý nghĩa |
|------------|---------|
| `ÚC - TÊN` | Chưa xử lý |
| `🔍 ÚC - TÊN - Đang kiểm tra...` | Đang AI kiểm tra |
| `🚨 ÚC - TÊN - THIẾU (...)` | Thiếu giấy tờ, cần bổ sung |
| `✅ ÚC - TÊN - Đang dịch` | Đang dịch |
| `✅ ÚC - TÊN - Đang khai` | Đã dịch xong, đang khai form visa |
| `✅ ÚC - TÊN - DONE` | Hoàn tất (luồng Dịch Thuật thuần) |

### 3. Trigger kích hoạt bot (đổi tên folder trên Drive)
| Đuôi folder | Hành động |
|-------------|-----------|
| `-DONE` | AI quét + kiểm tra đủ thiếu |
| `-CHECK` | Chạy lại kiểm tra (Sale bổ sung file) |
| `-Dịch` / `-dich` | Bỏ qua kiểm tra, dịch thẳng |

### 4. Fallback AI tự động
Hệ thống tự chuyển OpenAI → Gemini khi gặp lỗi 429 (hết quota).
Thêm `GEMINI_API_KEY` vào `.env` để fallback hoạt động.

### 5. Lỗi thường gặp & cách xử lý

| Lỗi | Nguyên nhân | Cách xử lý |
|-----|-------------|------------|
| `workspace_not_found` | Không tìm thấy `_files_meta.json` | Kiểm tra thư mục trong `translation_workspace/` |
| Lỗi Drive / token | `token.json` hết hạn | Xóa `token.json` → chạy lại để xác thực |
| Lỗi 429 OpenAI | Hết quota | Thêm `GEMINI_API_KEY` vào `.env` |
| Font lỗi tiếng Việt | Encoding Windows | Chạy: `[console]::OutputEncoding = [System.Text.Encoding]::UTF8` |
